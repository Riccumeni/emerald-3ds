# Dossier locali delle animazioni BW2

Piano e criteri: [BW2_ANIMATION_PLAN.md](../../docs/BW2_ANIMATION_PLAN.md).

Le cartelle `pokemon/<numero-nazionale>_<nome>/{front,back}/` e
`moves/<id>_<nome>/{player,opponent}/` sono predisposte per tutte le unità.
La sola esistenza della cartella non dimostra il completamento.

Ogni direzione deve ricevere `screenshot.png` e `demo.mp4` acquisiti dal
gioco. Ogni cartella dell'unità deve ricevere `metadata.json` e `verifica.md`
quando viene verificata. Le varianti usano `forms/` o `cases/`.

Nessun media è stato creato dalla sola preparazione del piano. Non inserire
file vuoti con i nomi delle prove. Le registrazioni e gli asset estratti
restano locali; i registri dei progressi risiedono in `docs/bw2-plan/`.
